2026 年 3 月 22 日下午，中国科学技术大学学生 Linux 用户协会在西区 3C101 教室开展了每周小聚活动。本次小聚的主题是吴擎宇同学带来的 Linux 科研环境实用配置指南。

吴同学首先介绍了常见的 SSH 配置技巧，包括本地、远程和动态端口转发，以及配置代理和跳板机的方法。随后，他讲解了 Docker 的安装步骤，并针对各种网络环境分享了多种拉取镜像的解决方案，以及配置 Docker Rootless 模式等。

![](https://ftp.lug.ustc.edu.cn/%E6%B4%BB%E5%8A%A8/2025.12.07_Typst_Intro/IMG_1398.png)

接着，吴同学梳理了 Nvidia 驱动与 CUDA 的安装建议，强调了通过包管理器安装以避免系统损坏的避坑指南。他对比了 venv、uv 和 conda 等 Python 虚拟环境工具的特点和差异，分享了处理复杂依赖冲突的实用排查思路。同时，他还分享了 top/htop、ss、iostat 等用于监控系统进程、网络和 I/O 状态的常用命令行工具。

![](https://ftp.lug.ustc.edu.cn/%E6%B4%BB%E5%8A%A8/2025.12.07_Typst_Intro/IMG_1402.png)

最后，吴同学介绍了 Linux 系统的底层基础知识，涵盖了操作系统的核心组成、内核空间与用户空间的隔离设计、系统调用、包管理器，以及启动流程。

本次小聚的幻灯片和视频回放已上传至 FTP：[每周小聚：Linux 科研环境实用配置指南](https://ftp.lug.ustc.edu.cn/%E6%B4%BB%E5%8A%A8/2026.03.22_Linux_utilities/)。
