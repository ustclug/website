2026 年 9 月 19 日下午，LUG 在西区 3C101 举办了软件自由日（Software Freedom Day）活动。

14 时，活动正式开始。首先，来自 USTC Minecraft 社群的 Lylighte/李沅达同学为大家介绍了 Minecraft 背后的自由软件生态。他结合去年搭建基于 Fabric 的校园服务器、今年建设独立材质与登录平台的经历，介绍了 Mod 加载器、性能模组、映射表等相关开源项目，也谈到了普通玩家如何从玩游戏开始，逐步参与服务器搭建、代码开发和社区维护。

![](https://ftp.lug.ustc.edu.cn/%E6%B4%BB%E5%8A%A8/2026.09.19_%E8%BD%AF%E4%BB%B6%E8%87%AA%E7%94%B1%E6%97%A5/photos/20260919_142345.jpg)

接下来，吴维卿同学为大家介绍了 Linux 的 HDR 支持。他从 HDR 的基本原理讲起，回顾了 2025 年初以来 Linux HDR 生态的快速发展，并结合自己的开发经历，讨论了系统和应用在支持 HDR 时需要考虑的问题。

![](https://ftp.lug.ustc.edu.cn/%E6%B4%BB%E5%8A%A8/2026.09.19_%E8%BD%AF%E4%BB%B6%E8%87%AA%E7%94%B1%E6%97%A5/photos/20260919_144046.jpg)

随后，Hanako 同学分享了她在 [nightcord.de](https://nightcord.de) 上运营 Mastodon 与 Matrix/Synapse 服务的经历。她以这些服务为例，介绍了不同的联邦方式，以及如何利用自由软件搭建社区服务、实现不同社区之间的互通。

![](https://ftp.lug.ustc.edu.cn/%E6%B4%BB%E5%8A%A8/2026.09.19_%E8%BD%AF%E4%BB%B6%E8%87%AA%E7%94%B1%E6%97%A5/photos/DSC04416.jpg)

茶歇之后，王永福同学介绍了 llm.ustc.edu.cn 平台的架构演进。他讲述了从部署开源项目，到修改推理引擎、补齐所需功能，再到向上游提交补丁的经历，并介绍了开发过程中涉及的 GPU 算子优化、并发死锁等工程问题。

![](https://ftp.lug.ustc.edu.cn/%E6%B4%BB%E5%8A%A8/2026.09.19_%E8%BD%AF%E4%BB%B6%E8%87%AA%E7%94%B1%E6%97%A5/photos/20260919_160136.jpg)

最后一个主题分享中，Kimi Code 和 DeepSeek Harness 的 \_Kerman 同学回顾了 Coding Agent 从代码补全、对话式编程到 Agentic Coding 的发展历程。他讨论了 Model 与 Harness 的关系、Programmatic Tool Calling 等新方向，也探讨了在 Agent 项目不断涌现的当下，什么样的工作可能有价值。

![](https://ftp.lug.ustc.edu.cn/%E6%B4%BB%E5%8A%A8/2026.09.19_%E8%BD%AF%E4%BB%B6%E8%87%AA%E7%94%B1%E6%97%A5/photos/IMG_8235.png)

主题分享结束后，活动进入闪电演讲环节，两位同学上台分享了他们与自由软件的故事。

![](https://ftp.lug.ustc.edu.cn/%E6%B4%BB%E5%8A%A8/2026.09.19_%E8%BD%AF%E4%BB%B6%E8%87%AA%E7%94%B1%E6%97%A5/photos/IMG_8236.png)
![](https://ftp.lug.ustc.edu.cn/%E6%B4%BB%E5%8A%A8/2026.09.19_%E8%BD%AF%E4%BB%B6%E8%87%AA%E7%94%B1%E6%97%A5/photos/IMG_8237.png)

17 时 30 分，本次软件自由日活动圆满结束。很高兴通过这样的分享与交流，同学们更多地了解了自由软件和开源社区。
