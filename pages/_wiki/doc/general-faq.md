## 搭建个人主页 {#personal-website}

如果你想要搭建一个个人主页，**我们首先推荐 [GitHub Pages](https://pages.github.com/)**。它是由全世界广泛使用的代码托管平台 GitHub 提供的**免费**静态网页服务，为每个用户默认分配 `<username>.github.io` 域名，在开发者及信息技术爱好者群体中具有较高的辨识度。

如果你想进一步获得更多个性化的体验，我们下一件推荐的事情就是**购买一个个人域名**。<https://tld-list.com/> 这个网站列出了市面上各种顶级域（TLD），并提供了不同注册商之间的价格对比。大部分常见的 TLD 注册价格都在**每年** 100 元人民币以内。购买域名后，你可以将其用到 GitHub Pages 上，也可以进一步发掘更多玩法，比如搭建邮箱等。我们相信一个个人域名是一项值得的投资，即使它需要每年续费。

除此之外，各大云服务商的免费套餐或额度，以及 GitHub Student Pack 中的免费体验等，也都是不错的选择。诸如 Amazon AWS 和 Microsoft Azure 之类的云服务商都提供了提供一定额度的免费云服务器（VPS）资源（通常为 12 个月有效），足够你在这期间学习 Linux 云服务器的搭建和维护。如果你想要拥有一个长期使用的云服务器，国内的云服务商如阿里云、腾讯云等也有低价的学生优惠产品，价格通常在每年 100 元人民币左右。

关于域名备案：

- 如果你想要使用自己的域名指向位于中国大陆的服务器提供网页服务（即 HTTP 服务），那么你需要为该域名进行 ICP 备案。备案手续通常需要数天到数周的时间，具体情况请通过你购买域名或服务器的服务商了解。
- 如果你的域名指向的是境外服务器，或者仅仅指向中国大陆的服务器但不提供网页服务的话（比如，仅用于非 HTTP 协议的游戏服务器），那么你不需要进行 ICP 备案，但一些域名注册商或云服务提供商仍然可能要求你进行实名认证，这通常是一个非常简单的过程（相比于备案而言）。
